# samuel phan

This is my portfolio. I'm an electrical engineering student at UC Irvine, and the site collects my projects, experience and education, with a contact form if you want to reach me.

Live at [samuelphan.vercel.app](https://samuelphan.vercel.app).

## Built with

- [Next.js](https://nextjs.org) 15 and React
- TypeScript
- Plain CSS
- [Vercel](https://vercel.com) for hosting and analytics
- [Resend](https://resend.com) for the contact form
